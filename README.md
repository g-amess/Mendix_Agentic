# Mendix_Agentic

**Status: alpha.** An org-wide, agent-agnostic toolkit for building Mendix apps with
[mxcli](https://github.com/mendixlabs/mxcli) and AI coding agents.

This repo is the *canonical* source. Tool-specific files (Claude Code, Cursor, etc.)
are generated by adapters under `adapters/`; nothing agent-shaped lives at the root.

## What this is

- A hub-and-spoke orchestration pattern for Mendix work: one orchestrator, many
  single-purpose spokes. Spokes never call each other.
- A policy guard (`policy/mxcli_guard.py`) that stops agents from writing to a
  Mendix `.mpr` outside the sanctioned path (SHOW → draft → check → approve → exec).
- A `bin/doctor` health check for prerequisites.

## What this is not (yet)

Phase 1 ships the foundation and guardrails only. No agents, no skills, no plugin,
no marketplace entries. Those arrive in later phases.

## Quickstart

```sh
bin/doctor          # posix
bin\doctor.cmd      # windows cmd
```

The doctor prints a PASS/WARN/FAIL report for Python, git, mxcli, Claude Code,
line endings and repo hygiene. See `bin/doctor.py --help` for flags (`--json` for CI).
